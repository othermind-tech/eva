# EVA — Release Notes

---

## v0.1.0 · Beta · October 2026

### What's New

- **First public release** — EVA is open source under the Apache License 2.0. The installer is published on the project's GitHub Releases page with a SHA-256 checksum and a build provenance attestation.
- **Self-hosted fonts** — Inter and JetBrains Mono ship with the app, so EVA does not request fonts from Google.
- **Reproducible builds** — the backend is built from hash-locked dependency files, and renderer obfuscation is optional and off by default.
